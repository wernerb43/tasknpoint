# Deploy

This deployment setup is based on [sesteban951/deploy_robot](https://github.com/sesteban951/deploy_robot),
an asynchronous framework for deploying control policies on the Unitree G1 humanoid
in both simulation (Mujoco) and on real hardware (Unitree SDK2).

For setup and deployment instructions — environment configuration, ROS2 / Conda /
Unitree SDK2 installation, and how to launch the simulation and hardware pipelines —
refer to the upstream repository:

**https://github.com/sesteban951/deploy_robot**

The structure here mirrors that repo (configs, hardware, policies,
simulation, utils), adapted for this project.
